# LESS Shop – GitHub Pages test

Upload all four files in this folder to the root of your GitHub repository:
- index.html
- creatine.webp
- night.webp
- magnesium.webp

Then enable GitHub Pages:
Settings → Pages → Build and deployment → Deploy from a branch
Branch: main
Folder: / (root)
Save

Your test site should then be available at:
https://sez-92.github.io/Less-shop/
